# S-40 transaction references

Numeric charging_session (or legacy session) references open the existing driver charging detail API, which checks ownership. Non-numeric legacy references are displayed without a misleading link.

Topup details remain pending S-35: no payment entity/detail API exists in this repository. Payment, payment_gateway and manual_receipt references display an unavailable-detail message. S-35 must supply a stable reference contract, an ownership-protected detail endpoint and screen. This part of S-40 requires product-owner agreement before acceptance and is not claimed complete.
